# DQT - Android GUI Testing Framework
## Overview
The growing user demands have driven modern mobile apps to become larger, more complex and constantly evolving. The DQT Framework is designed to enable more effective Android GUI testing to find bugs in such apps. Hundreds of bugs have been found by the DQT-series approaches, both in open-source apps (e.g., [Signal](https://github.com/signalapp/Signal-Android), [Firefox](https://github.com/mozilla-firefox/firefox)) and industrial apps from large commercial companies.

<br/>

## Approaches
**General Testing Approaches**
- [DQT](docs/DQT.md) [ICSE'24] : The first generation of Deep Q-network Testing, based on deep reinforcement learning.
- [DQT2](docs/DQT2.md): The second generation of Deep Q-network Testing, based on deep reinforcement learning and further enhanced by model-based testing.

<br/>

## Related Approaches
**Testing Enhancement Approaches**
- [NATE](https://github.com/Yuanhong-Lan/NATE-Android) [ASE'25] : A Network-Aware Testing Enhancer for network-related faults detection.

**Testing Evaluation**
- [AndroTest24 & SATE](https://github.com/Yuanhong-Lan/AndroTest24) [ASE'24] : The first comprehensive statistical study of existing Android GUI testing metrics with SATE (Statistical Android Testing Evaluation) Framework.
